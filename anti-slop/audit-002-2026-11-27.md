## Numbered Findings List (Mode 2 Audit)

1. **[R-39 / R-25] [HIGH / Hard Gate] Buttons, tabs, and links lack distinct `:hover` and `:active` states across the app, and Dark Mode `--accent-vermilion-hover` (`#DF3D22` on `#FFFFFF`) fails WCAG AA at `4.35:1`.**
   - *Where:* [index.css](../web/src/index.css#L42), [TopNav.tsx](../web/src/components/TopNav.tsx), [CommandDesk.tsx](../web/src/components/CommandDesk.tsx), [BroadcastStudio.tsx](../web/src/components/BroadcastStudio.tsx), [PublicCrisisWire.tsx](../web/src/components/PublicCrisisWire.tsx), [OpsMemoryAudit.tsx](../web/src/components/OpsMemoryAudit.tsx), [HybridBenchmarkPanel.tsx](../web/src/components/HybridBenchmarkPanel.tsx).
   - *Reason:* Adding semantic `:hover` and `:active` states (with a WCAG AA compliant dark vermilion hover token such as `#A82813` at `7.05:1`) restores clear tactile feedback on every interactive control in both themes.

2. **[R-34] [HIGH / Hard Gate] Undefined CSS variable `var(--semantic-on-device)` silently breaks semantic emerald emphasis in Light and Dark mode.**
   - *Where:* [BroadcastStudio.tsx](../web/src/components/BroadcastStudio.tsx#L454) (`items kept local`) and [OpsMemoryAudit.tsx](../web/src/components/OpsMemoryAudit.tsx#L566) (`PROMOTED TO AREA KNOWLEDGE`).
   - *Reason:* Replacing the undefined variable with `var(--state-ondevice-ink)` restores verified `6.14:1` light / `6.38:1` dark contrast and consistent on-device semantics.

3. **[R-03] [HIGH / Hard Gate] Sticky `TopNav` wraps into a tall two-row header (~120px) with horizontally scrolling tabs on narrow mobile viewports instead of reflowing into a dedicated mobile navigation pattern.**
   - *Where:* [TopNav.tsx](../web/src/components/TopNav.tsx#L61-L141) and [App.tsx](../web/src/App.tsx#L394-L471).
   - *Reason:* Reflowing `< md` navigation into a clean fixed bottom tab bar (with reserved bottom page padding and safe-area insets) keeps the top header to one compact row on phones without clipping tabs or eating screen height.

4. **[R-32 / R-39] [HIGH / Hard Gate] Three `role="tablist"` widgets miss WAI-ARIA APG keyboard arrow navigation and `role="tabpanel"` wiring, five form inputs/selects lack visible `<label>` elements, and audit filter buttons lack `aria-pressed`.**
