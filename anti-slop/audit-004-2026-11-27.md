## Numbered Findings List (Mode 2 Audit)

1. **[R-34 / R-25] [HIGH / Hard Gate] System status and navigation bar icons turn invisible in Light Mode on System Dark devices.**
   - *Where:* [MainActivity.kt](../android/app/src/main/kotlin/dev/sigapwire/android/MainActivity.kt#L50-L55) (observed live on Galaxy A55: white clock/Wi-Fi/5G icons on `#FFFFFF` top bar = `1.00:1`, FAIL).
   - *Reason:* `enableEdgeToEdge()` is invoked once without syncing `WindowInsetsControllerCompat.isAppearanceLightStatusBars` and `isAppearanceLightNavigationBars` to `!state.darkTheme` when the in-app theme toggles.

2. **[R-25 / R-34] [HIGH / Hard Gate] Dark Mode "Scrub PII & Send Answer" button fails WCAG AA text contrast (`1.52:1`).**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L341-L358)
   - *Reason:* `ButtonDefaults.buttonColors(containerColor = p.onDeviceInk)` inherits `#FFFFFF` text over bright mint `#6EE7B7` in Dark Mode (`1.52:1`, FAIL); setting `contentColor` to `#064E3B` (`p.onDeviceBg`) in Dark Mode raises contrast to `6.38:1` (PASS) while keeping Light Mode at `6.47:1` (`#FFFFFF` on `#0D6B53`).

3. **[R-03] [HIGH / Hard Gate] `windowSoftInputMode="adjustResize"` is declared on `<application>` instead of `<activity>`, and the scrollable column lacks `.imePadding()`.**
   - *Where:* [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml#L14-L18), [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L108-L114)
   - *Reason:* Android ignores `windowSoftInputMode` on `<application>`, so the on-screen keyboard can obscure `rawInput`, `fieldReplyDraft`, and submit actions until moved to `<activity>` with `.imePadding()` on the scroll container.

4. **[R-03] [HIGH / Hard Gate] Raw input `OutlinedTextField` has no upper height cap, expanding across 5+ phone screens on the Long Multi-Subdistrict Dump.**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L464-L470)
   - *Reason:* `heightIn(min = 130.dp)` without a maximum height or `maxLines` pushes the live token-budget router and primary CTA multiple screens below the fold; capping at `heightIn(min = 130.dp, max = 260.dp)` keeps controls reachable while scrolling long notes inside the editor.

5. **[R-03] [HIGH / Hard Gate] Token-budget router row collides horizontally and wraps awkwardly on `PREFER_ON_DEVICE (Cloud Fallback)`.**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L505-L523)
   - *Reason:* `Row(Arrangement.SpaceBetween)` places the token counter and route label with zero gap, causing text to touch flush and wrap left-aligned onto two lines on 411dp phones; reflowing cleanly with spacing prevents text collision.

6. **[R-03] [HIGH / Hard Gate] Non-wrapping metadata `Row`s in the `Area Knowledge` banner and `DispatchCardView` header risk clipping or crowding on narrow phones.**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L234-L253), [LiveAlertsScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L264-L289)
   - *Reason:* Placing `DISPATCH #N`, `SeverityTag`, `InferenceSourceBadge`, and timestamp (or `Area Knowledge Active (N)` and description) on a single rigid `Row` risks horizontal collision on 360dp-411dp viewports; reflowing with `FlowRow` / stacked header rows prevents clipping.

7. **[R-25] [HIGH / Hard Gate] Interactive button, field, and active mode-segment borders fall below WCAG 1.4.11 `3:1` non-text contrast.**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L305), [L335](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L335), [L397-L408](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L397-L408), [L436](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L436); [LiveAlertsScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L308)
   - *Reason:* `borderSubtle` measures `1.41:1` light (`#DDD9D0` on `#FFFFFF`) and `1.33:1` dark (`#2D333B` on `#1A1D21`), and the active mode segment `#FFFFFF` on `#F1EFEA` is `1.15:1`; applying `borderStrong` (`4.76:1` light / `6.60:1` dark) on interactive controls and the active toggle meets `>= 3:1` in both themes.

8. **[R-39] [HIGH / Hard Gate] Force-Cloud checkbox label text is not tappable, and the Field Verification reply field lacks a visible label.**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L326-L339), [L600-L617](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L600-L617)
   - *Reason:* Wrapping the checkbox row with `Modifier.toggleable(role = Role.Checkbox)` makes the entire row operable as one accessible control, and adding a visible `Field Verification Reply` label avoids placeholder-only labeling.

9. **[R-27] [HIGH / Hard Gate] Successful local PII redaction without `google-services.json` displays inside a red critical error box, and unconfigured `Live Alerts` has no next-step action.**
   - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L658-L671), [MainViewModel.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/MainViewModel.kt#L292-L300), [LiveAlertsScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L67-L98)
   - *Reason:* Styling `"Local PII redaction finished! Add google-services.json..."` as a red error contradicts a successful Stage 1 local privacy run (should use `warnBg`/`warnInk` setup guidance), and adding a `"Go to Field Capture"` button on the unconfigured `Live Alerts` card gives users an immediate working path.

10. **[R-06] [MEDIUM / Purpose-Gate] Situation and Dispatch headlines omit the `DESIGN.md` editorial `FontFamily.Serif` display typeface.**
    - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L764-L769), [LiveAlertsScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L325-L330), [L398-L403](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L398-L403), [L413-L418](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L413-L418)
    - *Reason:* Applying `FontFamily.Serif` to dispatch headlines and situation titles fulfills `DESIGN.md` Section 4 and gives the Android companion the same Crisis Newsroom voice as Web and Apple.

11. **[R-11] [LOW / Quality Lock] Several secondary buttons omit `RoundedCornerShape(6.dp)` and revert to Material 3 full-pill shapes.**
    - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L187), [L280](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L280), [L302](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L302), [L341](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L341), [L589](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L589), [L838](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L838), [L886](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L886); [LiveAlertsScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L377), [L466](../android/app/src/main/kotlin/dev/sigapwire/android/ui/LiveAlertsScreen.kt#L466)
    - *Reason:* Applying `RoundedCornerShape(6.dp)` consistently across all buttons enforces the `DESIGN.md` `8dp / 6dp / 4dp` geometry instead of mixing rectangular controls with pill capsules.

12. **[R-19 / R-31] [LOW / Quality Lock] Token-budget `LinearProgressIndicator` renders Material 3's default trailing stop dot.**
    - *Where:* [FieldCaptureScreen.kt](../android/app/src/main/kotlin/dev/sigapwire/android/ui/FieldCaptureScreen.kt#L524-L532)
    - *Reason:* Setting `drawStopIndicator = {}` and `gapSize = 0.dp` removes the decorative M3 end dot so the token-budget bar renders as a clean continuous meter matching Web.
