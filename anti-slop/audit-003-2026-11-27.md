## Numbered Findings List (Mode 2 Audit)

1. **[R-39 / R-32] [HIGH / Hard Gate] All custom buttons and `ShareLink` controls use `.buttonStyle(.plain)` with zero hover, pressed, or disabled visual feedback, and lack macOS keyboard shortcuts and VoiceOver hints.**
   - *Where:* [SigapWireAppleApp.swift](../apple/SigapWireApple/SigapWireAppleApp.swift#L82-L96), [BriefingWireView.swift](../apple/SigapWireApple/Views/BriefingWireView.swift#L155-L411), [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L269-L752).
   - *Reason:* `.buttonStyle(.plain)` removes pressed dimming, disabled opacity (disabled vermilion CTAs still look active), and macOS hover feedback; adding reusable `SigapButtonStyle` (`primary`, `secondary`, `subtle`, `onDevice`) with `isPressed`, `isEnabled`, macOS hover states, VoiceOver labels, and `Cmd+1`/`Cmd+2` view shortcuts restores full native affordance.

2. **[R-03] [HIGH / Hard Gate] Side-by-side `HStack` form/button rows and the 3-title segmented format picker squeeze or truncate on iPhone (`375pt-393pt`), while macOS stretches a single mobile column inside a default `TabView`.**
   - *Where:* [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L316-L349), [#L458-L494](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L458-L494), [#L710-L752](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L710-L752), [BriefingWireView.swift](../apple/SigapWireApple/Views/BriefingWireView.swift#L327-L332), [SigapWireAppleApp.swift](../apple/SigapWireApple/SigapWireAppleApp.swift#L32-L48).
   - *Reason:* Stacking action rows vertically on compact iPhone widths, replacing the cramped 3-long-label segmented picker with readable format controls, and giving wide macOS windows (`>= 900pt`) an adaptive two-column command layout delivers real Mac + iPhone reflow instead of one squeezed/stretched stack.

3. **[R-27] [HIGH / Hard Gate] `FirestoreSyncService` lacks an initial loading state (silently showing the offline sample before live dispatches arrive) and error banners have no Retry recovery action.**
   - *Where:* [FirestoreSyncService.swift](../apple/SigapWireApple/Services/FirestoreSyncService.swift#L12-L85), [BriefingWireView.swift](../apple/SigapWireApple/Views/BriefingWireView.swift#L95-L119).
   - *Reason:* Tracking `isLoadingDispatches` during initial Firestore bootstrap, rendering a structured SwiftUI skeleton card while loading, and providing a 44pt `Retry Sync` button on sync errors satisfies R-27 loading/empty/error completeness.

4. **[R-34] [HIGH / Hard Gate] `TextEditor` in `QuickTextIntakeView` omits `.scrollContentBackground(.hidden)` and explicit text foreground styling, showing a mismatched native white/black plate over warm newsprint/charcoal surfaces.**
   - *Where:* [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L443-L455).
   - *Reason:* Hiding the system editor background and applying `SigapTheme.ground(scheme)` + `SigapTheme.inkPrimary(scheme)` ensures crisp Light and Dark theme parity on both macOS and iOS.

5. **[R-35] [HIGH / Hard Gate] Post-remediation `xcodebuild` builds for both `SigapWireApple_macOS` and `SigapWireApple_iOS` (Simulator) must be verified cleanly.**
   - *Where:* `apple/SigapWireApple.xcodeproj` (`SigapWireApple_macOS` and `SigapWireApple_iOS` schemes).
   - *Reason:* Running `xcodebuild` for both Apple platforms with `CODE_SIGN_ALLOWED=NO` confirms Swift 6 strict concurrency and cross-platform `#if os(iOS)` / `#if os(macOS)` UI changes compile cleanly without errors.

6. **[R-01 / R-09 / R-20] [MEDIUM / Purpose-Gate] `BriefingWireView` renders `Lakukan Sekarang` and `Hindari` as plain gray bullets instead of semantic emerald/crimson safety callouts and omits the synced `provenanceCode` seal badge.**
   - *Where:* [BriefingWireView.swift](../apple/SigapWireApple/Views/BriefingWireView.swift#L188-L214), [SigapWireModels.swift](../apple/SigapWireApple/Models/SigapWireModels.swift#L255-L282), [FirestoreSyncService.swift](../apple/SigapWireApple/Services/FirestoreSyncService.swift#L330-L374).
   - *Reason:* Parsing optional `provenanceCode` from Firestore dispatches and styling `LAKUKAN SEKARANG` (emerald) and `HINDARI` (crimson) callout cards aligns Mac and iPhone visual hierarchy with Web and [DESIGN.md](../DESIGN.md).

7. **[R-14 / R-11 / R-31] [MEDIUM / Purpose-Gate] Inconsistent card corner radii (`10pt` vs `8pt`), duplicated hand-rolled status pills, and unframed `ID:`/`EN:` summary lines weaken design-system cohesion.**
   - *Where:* [Theme.swift](../apple/SigapWireApple/Views/Theme.swift), [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L361-L364), [#L433-L440](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L433-L440), [#L524-L531](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L524-L531), [#L634-L640](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L634-L640).
   - *Reason:* Centralizing `SigapCardStyle`, `SigapButtonStyle`, `SigapActionCallout`, and strict `8pt`/`6pt`/`4pt` radii in `Theme.swift` removes repetitive styling code and keeps every view consistent.

8. **[R-03 / R-05] [MEDIUM / Purpose-Gate] Top chrome stacks into two tall rows on iPhone above `TabView`, while macOS displays generic top tab chrome duplicated beneath the custom header bar.**
   - *Where:* [SigapWireAppleApp.swift](../apple/SigapWireApple/SigapWireAppleApp.swift#L32-L113).
   - *Reason:* Slimming the iPhone top bar to one compact row (keeping `TabView` bottom bar clean with an open-checks badge) and replacing macOS's redundant `TabView` chrome with an integrated Crisis Newsroom top navigation bar makes both platforms feel purpose-built.

9. **[R-19 / R-39] [MEDIUM / Purpose-Gate] `QuickTextIntakeView` lacks a visual token-budget progress bar and side-by-side/stacked "Stayed Local vs. Cloud-Safe" diff comparison.**
   - *Where:* [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L427-L442), [#L516-L590](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L516-L590).
   - *Reason:* Adding a determinate token-budget progress meter (`~X / 1,600`) and showing the redacted "Stayed Local" vs "Cloud-Safe" diff panes makes on-device privacy and cloud escalation immediately legible during live demos.

10. **[frontend-ui-engineering] [LOW / Quality Lock] Monolithic view files (`QuickTextIntakeView.swift` 766 lines, `BriefingWireView.swift` 456 lines) pack all sections into large computed properties.**
    - *Where:* [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift), [BriefingWireView.swift](../apple/SigapWireApple/Views/BriefingWireView.swift).
    - *Reason:* Extracting clean private subview structs inside the existing `.swift` files (without modifying `project.pbxproj`) improves readability and maintainability.

11. **[R-39 / R-03] [LOW / Quality Lock] Header pill says `"APPLE NANO READY"` (mixing Chrome/Android "Nano" naming into Apple Foundation Models) and iOS `ScrollView` lacks interactive keyboard dismissal.**
    - *Where:* [SigapWireAppleApp.swift](../apple/SigapWireApple/SigapWireAppleApp.swift#L56), [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L221-L253).
    - *Reason:* Updating the readiness badge to `"APPLE FM READY"` / `"ON-DEVICE READY"` and adding `.scrollDismissesKeyboard(.interactively)` + an iOS keyboard `Done` toolbar button keeps copy technically accurate and prevents the iPhone keyboard from obscuring CTAs.

12. **[R-03 / R-06] [LOW / Quality Lock] Synthetic drill preset chips lack an active selected highlight and the raw input box lacks a Clear button and empty placeholder text.**
    - *Where:* [QuickTextIntakeView.swift](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L6-L7), [#L397-L456](../apple/SigapWireApple/Views/QuickTextIntakeView.swift#L397-L456).
    - *Reason:* Highlighting the selected scenario chip, adding a `Clear` control (`44pt`), and showing an honest placeholder prompt when empty improves text intake ergonomics on Mac and iPhone.
